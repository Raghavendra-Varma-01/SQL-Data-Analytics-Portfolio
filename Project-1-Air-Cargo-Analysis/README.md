# Project 1 — Air Cargo Analysis

## Objective

Analyze airline passenger, ticket sales, and route information using SQL to improve customer experience and operational efficiency.

## Project Scope

The project focuses on analyzing four datasets:

- `customer` — Customer information and registration details.
- `passengers_on_flights` — Passenger travel and flight details.
- `ticket_details` — Ticket purchases, prices, travel classes, and airline brands.
- `routes` — Flight routes, airports, and travel distances.

## What It Is Used For

- Identify regular customers for targeted offers and customer retention.
- Analyze passenger traffic across flight routes.
- Identify busy routes to support aircraft allocation.
- Calculate passenger counts and ticket revenue by travel class.
- Analyze ticket prices and airline brand performance.
- Examine customer booking and travel patterns.
- Generate ticket sales summaries and route-level insights.

## SQL Concepts Used

- Database Creation and Data Import
- Entity Relationship Diagrams
- SELECT Queries and Filtering
- JOIN Operations
- Subqueries
- Aggregate Functions
- GROUP BY and HAVING
- Window Functions
