# Project 2 — Employee Performance Mapping

## Objective

Analyze employee information and performance using SQL to support HR reporting, salary analysis, and employee role mapping.

## Project Scope

The project uses three datasets:
- `emp_record_table`
- `data_science_team`
- `proj_table`

It focuses on employee details, departments, experience, salaries, performance ratings, and assigned job profiles.

## What It Is Used For

- Retrieve and organize employee information by department.
- Evaluate employee performance ratings.
- Rank employees based on professional experience.
- Analyze minimum and maximum salaries across different roles.
- Validate assigned job profiles against organizational experience standards.
- Calculate employee bonuses based on salary and performance ratings.
- Analyze average salary distribution across countries and continents.
- Support HR reporting and employee performance assessment.

## SQL Concepts Used

- Database Design and ER Diagrams
- SELECT Queries and Filtering
- JOIN Operations
- GROUP BY and UNION
- Subqueries and Nested Queries
- Window Functions and Ranking
- Views
- Stored Procedures and Functions
- Indexing and Execution Plans
- Aggregate Functions
